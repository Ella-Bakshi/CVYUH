This page presents the CVYUH project and its workspace.

What this page adds

The showcase adds no analytics, advertising trackers, forms, cookies, local storage, or session storage. It uses local styles and locally hosted fonts. Images, when present, are served from the same site.

Hosting information

The site is prepared for GitHub Pages. When hosted there, GitHub may process technical request information, including IP addresses, to serve and protect the site. Its handling of that information is described in the GitHub General Privacy Statement.

The site owner does not receive form submissions or analytics from this page. If hosting or site features change, this note should be updated to match.
